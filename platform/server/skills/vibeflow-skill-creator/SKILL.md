# 技能创作契约（自有）

**支持范围**　技能详情、私有及组织技能包已实测。通过技能管理接口保存或安装，使用 Agent 草稿联想和 get_skill 读取。

## 结构约定

- 内置技能位于 `server/skills/<name>/SKILL.md`。通过技能管理保存私有或组织技能，用户覆盖优先于组织和内置版本。
- 文件包含 `name`、`description` 的 YAML frontmatter 与 Markdown 正文。可用 `agents/openai.yaml` 提供显示名称、简述和草稿提示。
- 名称与目录名一致。新私有技能采用独立名称，避免和已存在的技能重名。
- `description` 是自动触发的判定依据：写清"做什么 + 什么场景用"（一句话带过触发词）。

## 正文该写什么

按"契约"思维写，不写教科书：
1. **输入/输出**：读哪些目录文件、产物落哪（目录契约见工作流）
2. **流程**：关键步骤的可执行序列（命令给全，能直接跑）
3. **常见坑**：该领域真正翻车的点（比通用知识值钱）
4. **与平台的衔接**：作业系统/caseDict 回写/可视化/报告的接口点

## 注册与使用

- 写完即注册（注册表按文件 mtime 自动失效缓存，免重启）。
- 调用：聊天里 `$<name>` 补全选中，或 agent 按 description 自动命中；agent 用 get_skill 工具读全文。
- 迭代：技能是活文档——一次任务踩的新坑就该追加进正文（同 memory.md 的分工：memory.md 记算例级经验，SKILL.md 记领域级经验）。
