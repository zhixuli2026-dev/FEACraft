# CSL style sources

The three unmodified styles come from the [Citation Style Language styles repository](https://github.com/citation-style-language/styles/tree/12174e29a13a413a6a1eb53530eb1e54f4896fe5). Each file includes its contributors and license metadata.

- `apa.csl` is American Psychological Association 7th edition.
- `ieee.csl` is IEEE.
- `chicago-author-date.csl` is Chicago Manual of Style 18th edition, author-date.
