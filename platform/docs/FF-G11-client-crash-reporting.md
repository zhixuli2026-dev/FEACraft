# FF-G11 客户端崩溃上报

React 错误边界、浏览器全局异常和未处理的 Promise 拒绝使用同一个上报入口。页面在五秒内按错误消息和堆栈前缀去重。错误边界尝试重新挂载显示层，之后可手动重新加载。

上报保留来源的站点和路径，以及有界的错误消息、堆栈和浏览器信息。请求体去掉当前页面的查询串及片段，也清除诊断文本中出现的完整当前页面地址。上报请求不发送 Referer。服务端对直接上报执行相同的来源过滤，去除 URL 中的用户名、密码、查询串和片段，并沿用凭据脱敏。管理员回读时应用同一套过滤，既有 JSONL 记录继续按原字节保留。

已登录账户可提交报告。组织管理员可读取最新报告，普通成员和匿名账户不能回读。报告按追加方式保存到本机 JSONL。读取默认 20 条，最多 100 条。独立验收走正式网页和 API，模型调用为 0。[验收入口](../server/client_error_browser_acceptance.py)

首轮真实 Edge 运行已各写入一条 React 边界、窗口异常和 Promise 拒绝报告。夹具在异步读取第二、三条请求头完成前断言请求数。下一轮先保存浏览器请求对象并等待真实响应，再核对请求头。[首轮只读核对](../../tmp/client-error-browser-1n0eb65v/first-run-observation.json)

真实 Edge 复验通过。React 错误触发一次重新挂载，窗口异常在五秒内只上报一次，超过五秒后同一异常可以再次上报。未处理的 Promise 拒绝也正常上报。四个浏览器请求均为 HTTP 200，请求体保留站点、路径和堆栈，页面查询串、片段及 Referer 均未发送。服务端验证了直接提交和历史回读过滤、8000 字符堆栈上限及最新条数限制。管理员可读，普通成员收到 403，匿名读写收到 401，空消息收到 400。原 JSONL 历史记录的字节保持一致。[最终验收](../../tmp/client-error-browser-x84se7og/client-error-result.json)
