# FF-D13 体等值面、变形与模态

打开已求解的 OpenFOAM 算例或 VTK 结果，在可视化会话的滤波器抽屉中添加「体等值面」「变形」或「模态」。选择生成的对象，在属性区修改场、倍率或相位，点「应用」后可在数据信息中核对实际输出范围。表面等值线、切面、流线和箭头继续从同一抽屉进入。

## 场和参数

| 滤波器 | 输入与行为 |
| --- | --- |
| 体等值面 | 对三维体单元的标量场提取真实多边形。允许逗号分隔的多个等值，留空取场范围中值，输入 `0` 使用零等值。没有三维体单元时提示改用表面等值线。 |
| 表面等值线 | 在外表面提取标量等值线并加粗显示，兼容已有 `VF_contour` 场景及其 `iso=0` 自动约定。 |
| 变形 | 按每点三分量向量乘倍率移动网格点。倍率支持零和负数。单位由输入向量决定，位移场按原坐标单位使用。 |
| 模态 | 三分量模态移动网格，一分量模态用于染色。相位以度为单位。实部和可选虚部按 `倍率 × (实部 × cos 相位 − 虚部 × sin 相位)` 合成。可直接读取已发布的 POD VTU。 |
| 流线、箭头 | 用户选定三分量向量用于积分和箭头定向，可以另选标量染色场。 |

点、单元场都支持。默认同名时优先使用点场，脚本可用 `association="cell"` 指定单元场，VTK 按邻接单元插值到点。缺场、分量不符及非有限值显示错误，应用失败时保留上一帧。 [VTK 体等值面](https://vtk.org/doc/nightly/html/classvtkContourFilter.html) · [VTK 位移](https://vtk.org/doc/nightly/release/9.2/html/classvtkWarpVector.html)

```python
VF_isosurface("零压与参考压", "p", (0, 1.25))
VF_deform("位移", "Displacement", 2)
VF_mode("第一模态", "PODMode_1", 1, 45, association="cell")
VF_stream("速度流线", "p", vector="U")
VF_glyph("速度箭头", "p", vector="U")
```

上述调用可保存至 `D-post/scenes.py`，也可逐条由可视化会话的 VF 控制台调用。源网格和已发布结果用作输入，实际显示结果留在当前会话。

## 验收

VTK 9.6.2 从解析网格提取出 48 个体等值面多边形，顶点坐标同时核对了零等值、另一条指定等值和网格内部点。对已求解的 400 单元 OpenFOAM 网格，在 0.5 秒压力场上得到 34 个多边形。用此前真实导热求解发布的 POD 文件独立回算 170 个表面点，复核相位换号与插值。 [数值验收](../../tmp/FF-D13-analysis-filters-20261122/native.json) · [POD 源报告](FF-D11-field-extraction.md)

两个 VTK 计算并发处理各 736,368 个单元的独立网格，核对各自等值坐标和变形范围。混合二维与三维单元时仅从体单元提取等值面。点场与单元场同名时，显式选择两种关联可得到各自数值。另检查标量误作向量、向量误作等值场、二维体等值面、非有限倍率和实虚部分量不符。 [数值与故障回执](../../tmp/FF-D13-analysis-filters-20261122/native.json)
