关键调用链：

1. **创建算例**：workspace 归属校验 → DB flush 得 case id → 写 StandardCase 文件 → commit。
2. **caseDict**：所有写入统一 `update_case_dict` → parse → 写文件 → 更新 `workflow_state/case_meta/dict_revision` → 调用方 commit。
3. **Agent**：会话/案例/profile 归属校验 → LLM SSE → 工具循环 → 危险工具审批 → append-only 事件落库。
4. **作业**：DB Job → Windows/WSL 子进程 → 日志文件+内存 backlog+SSE → 状态回写 → 可选 FTS 重建。
5. **可视化**：创建带 `user_id` 的 viz session → VTK/trame kernel → 所有者 token 经 HTTP/wslink proxy 访问。

## 6. 不可破坏的契约

- **文件是事实源**：case 文件不整体存 DB；caseDict 的 DB 字段只是镜像。
- **统一字典写入**：REST/Agent 不得绕过 `update_case_dict`；普通写、上传、删除也必须先 canonicalize 路径。
- `workflowState` 仅 `A/B/C/D/E/V`；专用 `/caseDict:advance` 强制 confirmed+expected_revision、禁止跳级，B/C/D/E 证据门控和 V/A 例外；目录为 `0-caseDict/A-geo/B-mesh/C-run/D-post/E-report/UDF/Ref`。
- 几何脚本：`build_geometry(ctx)`、`export_geometry(ctx, objects)`；scene schema `vibeflow.cadquery.scene.v1`。
- Agent 危险工具包括 `run_shell_command/propose_file_update/propose_text_replacement`；除 `full_access` 外必须审批，高危命令仍需拦截。
- profile 必须属于当前用户；approve 在工具副作用前先验证续跑 profile。
- PTY/viz session 必须属于当前用户；有效 JWT 不等于可访问他人 session。
- SSE 主事件：`ready/text.delta/reasoning.delta/tool.delta/tool.state/tool.result/goal.updated/goal.progress/approval.requested/message.completed/run.completed/stream.done/stream.error/request.*`。

## 7. 当前主要缺口

1. **生产隔离**：`wsl-sandbox` 已有 namespace/nobody/无公网/staging，但 cgroup、并发一致性、全入口接入未完整；Windows/普通 WSL 仍非硬隔离，Job/PTY/viz 不支持多 worker/多副本。
2. **存储一致性**：作业级 S3 staging 已有唯一快照、冲突预检、删除保护、幂等重试和成功清理；跨进程/跨副本原子提交与分布式锁、PTY/viz/索引等长任务一致性和故障恢复仍未形成全链路保证。
3. **部署验证**：Docker/compose/nginx 尚未在目标机端到端验证；Linux 容器终端不能复用 pywinpty。
4. **功能深度**：flotherm2foam 未接；通用 UDF 阶段工作流/更多类型、OpenFOAM v2406 索引、MPI 进程组取消/调度、更多求解器、异网格/实验数值验证、实验数据自动采集、多序列图和完整 V&V 证据仍待做。
5. **ParaView/CAD/PPT 长尾**：server-manager 通用属性引擎、完整 studio、多副本 cadscene、PPT Beautify/presets/图片重建/叙述视频和渲染验证未实现。
6. **团队能力**：支付/seat 管理、OIDC/admin、离线许可、审计中心、完整配额覆盖和负载/渗透测试待做。
7. **CLI agent**：仅 opencode 有额外契约注入；通用终端仍是多 CLI 启动器，F58 隔离 CLI PTY 已验证（namespace，不是长期 Docker 容器）。Codex 已有独立 stdio 协议客户端，但账户/额度/UI/沙盒及完整 Agent 运行链仍待实现。

## 8. 踩坑速查

| 问题 | 当前处理方式 |
|---|---|
| Windows 双绑 8000 导致请求落旧进程 | 先核对进程；dev-up 只精确清理自身 PID 文件记录的后端/mock |
| SSE 收尾早于订阅 | 原子返回 queue+backlog；已结束立即补 done |
| SSE done 被可选 FTS 拖住 | 先持久化终态并通知订阅者，再做可选索引重建 |
| 多个 PTY 后 LaTeX/文件任务 queued | PTY 阻塞读必须走每会话独立执行器，不得占满 asyncio 默认池 |
| caseDict 变体路径绕过 | `PurePosixPath` 规范化后再比较，不只比较原始字符串 |
| 未纳管 DB 上 `alembic check` 失败 | 先跑 `schema_diff.py`；版本缺失不等于业务表漂移，禁止盲目 stamp |
| `create_all` 未加新列 | 用 Alembic 显式迁移；它只建缺失表 |
| Vite 构建与类型检查混淆 | 正式验证跑 `npm run build`（含 `tsc -b`），不要截断错误输出 |
| trame 函数式监听不触发 | 用 `@state.change`，不要依赖类式 `@TrameApp` 装饰器收集 |
| VTK filter 被 GC/段错误 | filter 链保活；跨函数输出 `DeepCopy` |
| trame 远程白屏 | interactor、首次 Render+update、change 后重 Render 缺一不可 |
| 本地 SCNET/viz/mock LLM 空 502 | 系统代理不能拦截回环；本地客户端用 `trust_env=False`，公网 LLM 保留代理；viz 流式响应不转发上游 Content-Length |
| xterm 6 选择器 | 根类名是 `.terminal`；E2E 先激活终端页签再输入 |
| dockview 点击不生效 | E2E 使用 pointerdown/up/click 序列 |
| WSL OpenFOAM 命令不存在/版本不符 | 先 `source /usr/lib/openfoam/openfoam2406/etc/bashrc`；带变量的 Bash 命令用 `wsl --exec bash -lc`，避免提前展开后混入 1912 |
| Windows 中文测试输出乱码 | 不拿乱码判断断言；必要时显式 UTF-8 输出 |
