# CLI 宿主私有文件的用户归属计量

2026-11-07，接续 [私有脱敏缓存](cli-private-vault-capacity.md)。此前用户存储用量统计只包含公共文件和回收站，宿主 CLI 账户与会话文件仅参与节点总量检查。现在它们进入现有用户用量展示和 `check_storage_quota` 所使用的库存。

## 新旧目录与归属

新会话工作目录改为 `.private-cli/users/<user_id>/sessions/<session_id>/workspace`，输入等兄弟目录随会话处于同一用户命名空间；初始化前验证正整数用户 ID 与标准 UUID。账户目录继续沿用 `.private-cli/users/<user_id>/<runtime>/...`。因此在数据库 owner 提交之前启动失败，实际留下的文件也仍可归属给该用户。

旧 `.private-cli/sessions/<session_id>` 保持原位置，不自动移动或删除。新增 `cli_private_usage` 在有界目录枚举后分批查询数据库 `NativeCliSession.id/created_by`，将旧目录计入实际创建者。扫描前后复核目录集合和设备/inode 身份；检测变化时拒绝，不能按一个已过时的列表静默漏算。

无法找到数据库归属的旧目录仅在完整扫描证明字节数为零时不计字节；若存在文件内容，则返回用量无法核验并保留文件。不会把未知内容分配给任意用户，也不会因 TTL 或失败自动清除。此时相关配额查询可能返回 503，需要后续基于证据的目录对账，不能把未知状态按零计量放行。

## 计量与配额边界

用户扫描在公共 FS/S3 库存之后扫描当前用户的宿主私有目录，以及归属匹配的旧会话目录。目录枚举、数据库读取和文件扫描使用同一个截止时间；条目数累计受同一上限控制，取消仍等待同步文件工作结束后才归还并发槽。

已有私有字节因此参与套餐存储额度的现有检查，可以阻止进一步通过该检查的写入。**CLI 初始化、vault 和原生程序新增字节本身的用户级预留尚未全部接入**，不能将本次“用量归属和已有额度检查”声称为所有 CLI 写入的原子用户准入。节点级预留和周期检查继续保留。

本次只包括宿主私有根；WSL 原生私有根总量、运行节点之外的数据和未知历史归属仍需后续。新路径命名是平台正常写入的归属契约，不能代替 OS 沙箱来防止不受信任的本地进程跨目录写入。库存是有界观察，不是相对于所有外部文件写入的原子快照。

## 扫描失败诊断

`node_storage_budget.observe` 为异常附加有界元数据：阶段（锁、预留、公共库存、私有库存、空间检查）、耗时、条目数、已观察字节数、异常类型、errno 及允许列表中的原因。CLI 检查失败时记录这些字段和会话 ID，不输出文件路径、内容、密钥或任意底层异常文本。

这能区分扫描条目上限、扫描期限、链接等原因；此前运行期首次未知拒绝因缺少底层记录，**仍未证明根因或修复**。本次只实际验证了条目上限对应的诊断字段，不把新诊断能力当作已经解决慢扫描。

## 实际验收

显式入口 `platform/server/live_llm_cli_private_usage_acceptance.py --source-profile-id 26 [--postgres --s3]`。FS/SQLite 和真实 SeaweedFS/PostgreSQL 各 9 项，共 **18 项实际基础设施检查**，纯协议/模拟故障 **0 项**：

1. 已安装的真实 Windows CLI 使用新用户目录初始化并关闭，根进程出生身份核验退出。
2. 实际账户目录新增 8 KiB，仅改变对应用户的用量。
3. 尚无数据库 owner 的新会话目录新增 4 KiB，仍计入其用户。
4. 第二个真实注册用户会话新增 32 KiB，不改变第一个用户用量。
5. 在隔离算例内，将已确认退出的会话目录移至旧布局，数据库创建者归属计量不漏算也不重复。
6. 真实空的旧无主目录不产生虚构字节或用户。
7. 旧无主目录写入真实文件后拒绝核算，文件哈希保持不变。
8. 在隔离数据库把实际套餐设为 1 MiB，真实 2 MiB 私有文件使生产额度检查返回 429；随后恢复套餐。
9. 将实际扫描条目上限设为 1，触发真实目录超界并检查诊断阶段、条目数和 `entry_limit` 分类。

证据：[FS/SQLite](../../tmp/live-cli-startup-4bqn_rcd/cli-private-usage-checks.json)、[S3/PostgreSQL](../../tmp/live-cli-startup-xak9vmz5/cli-private-usage-checks.json)。两个真实 CLI 根已退出，API 端口关闭，临时 PG 已删除，真实对象存储已停止，节点预留无残留。旧目录移动及删除无主算例文件仅发生在此次明确创建的隔离目录，开发数据库和部署目录未变更。
