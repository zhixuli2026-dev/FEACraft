# 启动身份缺失：原生内核作用域与后续接入

2026-11-07。本阶段实现并实际验证 cgroup v2 控制原语，以及固定启动门在发送 HELLO 前加入作用域的能力。它是补齐 `host_ready` 后未知 WSL 身份窗口的前置工作，**尚未接入请求持久化或恢复接管**。现有缺失身份的记录继续拒绝清理，不减少主线未完成数量。

## 已实现的行为

`app/services/process_cgroup_native.py` 只接受 64 位十六进制启动 nonce 和精确结构的作用域描述，不接受任意路径或 PID。固定父目录为 `/sys/fs/cgroup/vibeflow-native`；打开实际目录后验证 cgroup v2 文件系统、root 所有权和写权限，再绑定启动 boot ID、设备号、父目录 inode 和作用域 inode。

创建采用排他 mkdir。加入操作仅把调用中的固定门自身写入 `cgroup.procs`，随后核对实际成员关系。撤销操作对已绑定作用域写入 `cgroup.kill`，观察 `cgroup.events` 的人口归零，再由内核 rmdir 撤销后续加入；有进程竞争加入而不能删除时，在同一有限期限内重试。过期、身份变化、权限失败均不算成功。控制者不能撤销自己所属的作用域。

`process_gate.py` 新增可选的 `--native-scope`，只允许外层 WSL 门使用。它检查启动 nonce 和控制模块 SHA256，执行同一份已校验字节，并在 HELLO 之前加入作用域。既有调用者尚未传入这一参数；后续不能把“参数存在”当作已持久登记，必须先完成下述接入顺序。内部 PID namespace 的后代继承已经加入的作用域。

原语不把 WSL 作用域不存在解释为 Windows 宿主已经退出，也不凭主机重启推定所有记录完成。不同 boot ID 当前直接拒绝。它也不构成任意 root 程序的防逃逸沙箱：原生 root 门必须是固定可信代码，用户程序仍须使用已有低权限执行策略。

## 本阶段实际证据

[最终内核与启动门验证](../../tmp/native-cgroup-0fc80dac33724f9cbeb0a1016844d58b/result.json)保存执行源码 SHA256、时间、作用域身份及真实进程观察。在实际 WSL 内核 `6.18.54.1-microsoft-standard-WSL2` 上通过 10 组场景：

- 排他创建；拒绝控制者自我撤销；实际 nobody 后代无法迁入祖先 cgroup。
- 错误 boot/inode 和路径穿越描述被拒绝，活动成员和作用域外进程保持存活。
- 已调用 setsid、忽略 SIGTERM 的低权限后代仍被 cgroup.kill 停止；作用域外进程不受影响。
- 撤销后迟到的加入失败；撤销前已打开的 `cgroup.procs` FD 在删除后写入得到真实 `ENODEV`，调用者成员关系未变化。
- 同名重建得到不同 inode，旧描述不能加入、观察为匹配或杀死新作用域。
- 实际启动门对已撤销作用域、控制模块哈希变化和其他启动 nonce，在 HELLO 前失败；不放行负载。
- 已加入但未放行的实际启动门可由作用域撤销停止；正常放行的固定 Python 负载在真实 PID namespace 内继承作用域。

按场景用途划分为 8 组实际基础设施、2 组描述/协议故障测试，均无模型行为。测试结束时 5 个记录出生身份均实际退出，所有测试创建的作用域已撤销，未清理其他作用域。早期原语和接入版本的证据分别保留于 `native-cgroup-e57ea36437ac4b9897a820d5c746d30b`、`native-cgroup-71f4b0c2d3e741a3bccf91f4827156f7`、`native-cgroup-c58394284cb743e6b9ddf9dfaf4df1b5`；它们不代替最终源码绑定。

启动门是共享组件，因此另执行现有真实恢复链路的兼容验收：[准备取消/预留释放](../../tmp/sandbox-recovery-ui-retirement-rfjcv5tx/image-live-owner-checks.json)的 3 项基础设施和 1 项证据篡改故障通过，[9 个已登记进程身份均退出](../../tmp/sandbox-recovery-ui-retirement-rfjcv5tx/cleanup.json)。这是 SQLite 兼容验证，不是新增 cgroup 持久恢复的端到端验收，也不代表已完成 PostgreSQL 接入。

[本轮真实模型记录](../../tmp/sandbox-recovery-ui-retirement-rfjcv5tx/live-result.json)：北京时间 12:48:11、12:48:13，`api.deepseek.com` / `deepseek-flash`，2 次 HTTP 200，共 8530 tokens，模拟 LLM 为 0。模型实际选择文件工具，读取从保留快照恢复的随机内容，流式回复及持久记录通过；严格仅回复凭证字符串的要求仍为 false。本轮未修改开发数据库、认证配置或 schema。
