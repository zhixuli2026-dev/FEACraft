## 用户可见行为

报告面板可构建 HTML/DOCX、取消当前构建、刷新状态与产物、进入作业面板，并直接打开生成的报告。控件与当前用户、算例绑定，离开时停止轮询并中止前端请求；服务端作业不会因页面关闭而被误取消。

构建期间阻止重复点击，使用服务端已有幂等键。若服务端已经接受请求但响应在网络中丢失，界面保留原键并提示“确认提交结果”；用户点击后沿用原请求，不创建重复作业。同一标签页的刷新会从 `sessionStorage` 恢复已知作业编号，只查询状态。未知提交结果不会在刷新后自动 POST。

请求被拒绝时显示原因并允许修正后重新构建；查询断线时保留原作业，可刷新或切换回来继续查询。取消请求和实际完成分开显示，查询覆盖 queued/running、结果发布收尾、failed/cancelled/interrupted 以及需恢复检查状态。运行中取消已真实验收；本轮未专门构造 worker 中断终态，不能把代码分支当作对应实际故障证据。

浏览器状态只用于定位服务器记录，不是任务终态来源。当前恢复提示限于同源、同一浏览器标签页；新设备/其他标签页仍通过作业历史查找，不宣称跨设备恢复。

## 图表修正及原件保持

Pandoc 会将报告本地 SVG 嵌入为 HTML 的 `<svg>`。旧阅读器只保留 HTML/MathML，导致图表被过滤。现保留经 DOMPurify 过滤后的 SVG 图形，拒绝 SVG image/use 的外部或未封存引用，并为图表设置可访问名称。实际恶意脚本、onload 和外部 image/use 测试未执行脚本或发起相应网络请求。

Pandoc 的 DOCX 可只带 Word SVG 图片引用 `asvg:svgBlip`，不带旧式位图引用。原 Mammoth 读取不到这张图。新增转换副本兼容层，仅在没有既有 embed/link 时将 SVG 内嵌关系提供给语义转换器；已有位图回退保持原样。**原始 Blob 不修改，下载仍是打开时的 DOCX 原件。** 实际下载与固定发布产物 SHA-256 一致。

JSZip 3.10.2 原已是间接依赖，现声明为精确直接依赖；锁文件仅根依赖声明变化，没有升级其他依赖。
