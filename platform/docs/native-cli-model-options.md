# 原生模型参数与分页目录：N4-03.g2b3h

2026-11-03。沿用 API / Sign in with ChatGPT 商业部署方向，本单元将原生推理强度、推理摘要与本次服务档位接入已有回合准入、容量续跑、原生恢复及计划模式。没有新增数据库表或迁移。

## 请求与执行

`POST /api/v1/codex/sessions/{id}/turns` 和 `turns:stream` 接受可选对象：

```json
{
  "model_options": {
    "effort": "high",
    "summary": "detailed",
    "service_tier": "default"
  }
}
```

| 平台字段 | CLI `turn/start` 字段 | 行为 |
|---|---|---|
| `effort` | `effort` | 显式指定本次请求的推理强度；计划模式同时写入 `collaborationMode.settings.reasoning_effort`，避免被协作模式覆盖 |
| `summary` | `summary` | `auto` / `concise` / `detailed` / `none`；表示摘要方式，不是原始思维链 |
| `service_tier` | `serviceTierForTurn` | 仅指定本次原生 turn 的服务档位，不改写线程的长期档位 |

effort / service_tier 接受 1 至 64 个 ASCII 字母、数字、点、下划线或连字符，首字符必须为字母或数字。允许 CLI 目录中的新自定义标识，不固化为旧版 low/medium/high 枚举；不接受模型名、任意 config、指令、路径或未知字段。参数中出现已知私密凭据时在准入前拒绝，不写入公开回执。

字段缺省、null、空对象都不发送对应覆盖，并保持没有选项的旧幂等摘要格式。设置了选项时，规范化对象进入请求摘要；相同消息 ID 改变任何选项返回 409，不会再次调用模型。空字符串不等于缺省，接口拒绝空字符串。

显式选项在同一平台回合的容量续跑尝试中保持一致；原始用户消息仍不自动重发。`turn.admitted` 增加 `model_options` 作为已提交请求的事实，历史读取/SSE 可以恢复。此回执表达请求意图，不证明 CLI 或服务商没有钳制或转换参数，也不证明实际收费档位。

模型名继续通过已有会话设置绑定，不能借 model_options 绕过模型/凭据/权限归属。原生恢复允许对新回合显式设置这些参数；服务端没有新增跨分支复制 UI 参数偏好的机制。留空意味着交给原生 CLI 的默认或恢复设置，不承诺跨 CLI 版本/进程保存所有隐式偏好。底层 schema 将 effort/summary 描述为可能作用于后续 turn 的覆盖；本单元不主动清空这些原生状态，也不把留空解释为“关闭推理”。

## CLI 模型目录

`GET /api/v1/codex/sessions/{id}/models?cursor=...&limit=...` 增加分页参数：limit 为 1–100，默认 50；游标最多 4096 字符，原样传递给 CLI `model/list`。目录仍通过有归属的活动 CLI 会话读取，执行中不接受环境查询。

公开模型数据增加 `serviceTiers` / `defaultServiceTier`，保留推理选项。顶层与嵌套能力只保留白名单字段，校验字符串、布尔、数组与游标边界，额外字段不回传。模型是否实际接受某个选项由 CLI 和选定服务商决定；目录是所选 CLI 的元数据，不代替远端服务商兼容性保证。

浏览器环境检查最多取 4 页、每页 100 项，拒绝重复游标，目录截断时显示提示。完成后沿用现有流程关闭检查会话；不保存个人 CLI 登录态。匹配当前模型的目录项为推理强度和服务档位提供可选值，自定义模型仍可手动填写。

## 界面与历史

原生聊天增加“原生模型参数 · 下一条消息”折叠区，三个字段默认均为空。执行中锁定修改；模型/配置/运行时改变或页面重载时清空未提交选项，避免把另一个模型的选项无提示带入。浏览器参数草稿只在组件内存中，当前组件内的连续发送会继续使用可见选择。

运行记录另有“本次请求的模型参数”，从已提交事件读取，刷新后仍可查看。它与下一条消息的草稿分离。沿用实际 340px dock、深浅主题和键盘焦点；紧凑标签/输入布局可同时看到三个字段，任务输入区持续可见。整个工作台移动版不在此次范围。
