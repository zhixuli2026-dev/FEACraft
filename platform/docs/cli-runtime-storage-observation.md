# CLI 运行期宿主存储检查

2026-11-07，接续 [私有目录写入准入](cli-private-storage-admission.md)。启动后的 CLI 会继续写入数据库、日志和临时文件，启动前的预留不能覆盖这些增长。本次新增独立周期检查，超限或不能确认用量时通过既有关闭链停止实际进程并保存失败原因。

## 实现和边界

`node_storage_budget._capacity` 供准入与运行期检查共用：在同一 OS 锁下扫描公共根、宿主 `.private-cli`，加上实际活动预留，检查节点总量和公共/私有目标卷剩余空间。`observe` 使用自己有界的扫描期限，不创建预留，不继承已经过期的 CLI 启动请求期限。

`Session.observe_storage` 在激活后运行，完成一次扫描后间隔 5 秒。扫描移到线程并在取消时等待其排空；它与 SQL 续租任务分离，较慢扫描不直接阻塞续租。正常关闭也等待检查任务结束。容量超限保存 `node_storage_full`，链接/特殊文件/无法完成的扫描保存 `node_storage_unavailable`，均通过实际进程停止与持久记录链处理。

原生程序会删除临时文件；遇到 FileNotFoundError 时最多重扫整个库存三次，累计条目数和同一截止时间不重置。持续变化、链接及其他未知状态仍拒绝。扫描不是原子快照，不能阻止两次检查间快速增长，也不是 OS 硬额度。磁盘 I/O 本身仍可能等待内核返回。多个会话的扫描竞争和大目录性能仍需后续全局预算工作。

异常停止保留私有文件；S3 已启动会话的未同步 staging 不自动发布或删除，继续阻止将其误判为已清理。WSL 原生私有根不在此次宿主库存内，不能据此声称 WSL 额度完整。活动模型回合的停止、审批、fork、API 退出恢复尚需真实模型及故障专项验收。
