# 创建暂存安装中断恢复

2026-11-05，N2-06 第十四批。新建算例、ZIP 导入、算例/工作区复制及备份恢复共用的本地安装流程，已补齐临时文件链接到正式文件后、移除临时链接之前的进程退出窗口。

## 实现

新暂存记录采用 `vibeflow.provision-stage.v2`，保留原文件摘要、账户及存储绑定，增加创建进程的系统身份与正式目标路径。恢复仍先取得账户数据库锁，随后处理暂存，再读取 pending 创建计划、目录占用声明和正式文件。这样不会因为它们仍有两条硬链接而被后续普通文件校验拒绝。

恢复只清理系统确认已退出的创建进程留下的完整暂存。文件有两个链接时，必须证明它与记录中的正式目标是同一文件且总链接数为二；正式目标必须属于当前账户的创建元数据或算例目录。清理只移除临时链接，正式文件继续由既有 SQL 提交证明决定保留或回滚。第三条链接、外部修改、其他账户目标和不明进程身份均保留。

v1 记录继续执行原保留期与摘要规则，不能凭旧记录推断新目标。新 v2 记录无需等待保留期：进程退出证明与账户锁共同控制清理。正常存活进程的记录继续保留。后台维护使用同一入口，不再在恢复创建计划之后重复扫描暂存。
