| 算例声明 | 原生映射与实际核对 |
| --- | --- |
| `materials` | 密度和黏度用于不可压流，导热参数进入热传导，弹性参数进入结构输入，介电常数进入静电介质。可压流、多相和五区共轭传热分别核对各自的材料与物性。 |
| `regions` | 实际绑定几何体、网格和物理区域。多孔阻力、线性动网格和多区域共轭传热均完成求解。不存在的几何体、网格区和未覆盖的 CHT 材料列表拦截。 |
| `interfaces` | 原生机械接触、周期边界、热耦合面、静态与移动 Overset、电连续共用面，以及流体压力、声压到结构的封存载荷均有实际输入与结果。 |
| `boundarySets` | 核对现场网格上的边界条件、单位、时程、确认状态，覆盖速度、压力、温度、热流、位移、力、电压、电流及声阻抗。 |
| `loadCases` | 活动载荷选择边界、物理和材料。`icoFoam` 运动黏度从 0.001 到 0.002 m²/s，两档原生速度场与各自导出包一致。导热、弹性、静电和共轭热也有活动材料证据。 |
| `initialConditions` | 均匀、历史检查点、异网格映射、解析公式和测量 CSV 均进入实际求解。映射验收移除了本机源发布缓存。 |
