# 报告阅读器固定发布版本

2026-11-05，N2-05 的实际页面消费补充。主线仍为 22 完成、12 进行中、19 待开始，剩余 31；本次不关闭 N2-05 或任一全功能任务。

此前 HTML/DOCX 阅读器从可变工作区路径读取，下载按钮又重新请求该路径。用户打开第一版报告后，后台发布第二版，可能出现页面显示第一版、下载得到第二版的情况。

现在打开标准报告 `E-report/build/report.html` 或 `report.docx` 时，先通过报告结果接口取得发布 ID，再用该 ID 请求不可变报告文件。阅读器保留这次读取的原件 Blob，页面转换与下载使用同一份数据；后台新发布不会替换已打开文档，用户点击“重新读取”才选择最新版本。普通 HTML/DOCX 工作区文件也保留打开时的原件供下载。

版本条显示报告代次及打开时的输入有效性。无当前发布时明确标为工作区文件；版本检查出错、数据损坏或指定版本读取失败均显示错误，禁用下载，不回退到可变路径。重新读取可以在故障消除后恢复。切换文件/算例会中止旧请求，已迟到的旧结果不更新新页面。

正式报告由现有 Pandoc 构建内嵌图片及公式；已发布 HTML 遇到未嵌入的工作区图片不会改读当前图片，避免历史报告混入新资源。普通工作区 HTML 的相对图片行为保持原状，其多文件资源没有被声明为已发布快照。此次不实现任意历史版本选择、刷新后恢复历史选择或全格式产物浏览。

实现为 `platform/web/src/utils/documentSnapshot.ts` 和 `panels/DocumentPanel.tsx`。复用原报告结果/产物接口，后端源码、数据库 schema 和开发 API 未改动。
