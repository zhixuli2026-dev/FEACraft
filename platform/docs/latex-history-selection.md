## 已交付行为

LaTeX 生成的 PDF 阅读器提供任意历史版本选择，按 main 通道分页。PDF.js 分段读取、下载和 SyncTeX 均固定同一个 publication ID；每次读取还校验文件版本。历史版本缺失或损坏时明确失败，不换成当前工作区文件。默认打开且没有发布的普通 PDF 保留原读取方式。

界面区分最新发布、当前过期和历史发布。选择历史 PDF 后双击定位，展示该次发布保存的只读源码与目标行，不跳转到已经改动的工作区源码。“重新读取”回到最新版本并清除旧源码。普通 PDF 回跳新增 expected_file_version 校验，文件已变化时在原生查询前拒绝请求。

历史列表采用 (created_at DESC, id DESC) 总序与 before_id 游标，支持同时间戳记录和多 main 通道；limit 范围 1..100，默认 50，前端每页 20。跨算例、跨 main 和不存在的游标被拒绝，所有权检查保持有效。

`latex/artifact` 支持 HEAD、完整 GET 和 Range，使用经过发布 manifest/摘要验证的原件。2026-11-06 首轮历史版本验收使用完整原件的内存读取。2026-11-19 改为分块校验，只暂存响应所需内容，完成了文件系统和真实 S3 的 40 MiB 验收。[历史原件下载复验](latex-artifact-streaming.md)

源码区修正了窄窗口回跳时标题和关闭按钮被滚出的缺陷，代码区域独立滚动。页码操作明确标为“为工作区文件添加页码”；它仍处理当前工作区文件，不能宣称历史 PDF 派生操作已实现。
