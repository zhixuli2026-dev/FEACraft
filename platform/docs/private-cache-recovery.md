# 临时输入缓存退出恢复

2026-11-05，N2-06 第十二批。新增两类缓存的进程归属记录与退出后清理：S3 算例读取视图 `.case-read-views`，以及作业封存前下载来源的 `.attempt-sources`。两类缓存均已接入实际调用入口和后台启动、周期维护。

每个新缓存使用独立 UUID 容器，记录本机存储根目录、缓存类别和创建进程的系统身份（包含出生标记）。文件写入前刷盘保存路径、大小与 SHA-256。维护任务只对系统确认已经退出的创建进程进行恢复；存活、身份不匹配、其他主机或无法确认的进程均保留缓存。

清理先核验完整目录和文件，再逐文件重验删除，最后移除已知空目录。外部修改、额外文件或空目录、部分写入、硬链接、损坏记录和旧无记录目录均保留。后台恢复不使用递归删除；正常调用退出仍沿用调用者独占临时目录的清理行为。缓存维护在账户扫描之前执行，因此未注册账户时也能恢复节点自身的临时缓存。
