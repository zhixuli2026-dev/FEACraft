# RB-12 部分验收：S3 文件读取的恢复额度

2026-11-06：文件树、文本/二进制信息、文件版本、原始 GET/HEAD、caseDict 的五个路由处理器、六处协调器调用接入账户额度。读取前可能恢复文件事务并刷新 S3 HEAD，因此这些物理写入也需要预留空间。

入口先完成授权，再按工作区所有者持久预留额度，随后取得算例锁并运行原有恢复。响应完整生成后结束读取事务，再关闭账户额度，保证结算不随依赖会话退出时的回滚丢失。404、版本冲突、范围错误和非法路径同样执行关闭；没有提前提交业务写入。FS 保持原有读取流程，其恢复空间由共用本地文件事务层准入。

账户正在结算时，仅重试尚未成功的准入；不重放恢复或已生成的读取结果。重试截止时间使用存储盘点超时配置，等待可取消。这个截止时间约束重试，不代表所有 SQL/网络 I/O 已具备整次硬期限；后者仍属 RB-14。

手动 S3 文件恢复原先已通过 `storage_operations.hold` 接入逐笔远端预留，本次核对后保留，不叠加重复额度。下载的 Range、多段、HEAD、固定版本和并发替换检查保持原语义。

本轮双库额度与等待检查 32 项、S3 事务兼容 14 项、S3/FS 下载行为 33 项，以及两后端共用的协议检查 6 项，共 85 个不重复检查通过。其中等待策略使用受控繁忙响应验证截止与取消；没有模拟 LLM 调用。真实 LLM 验收另见 [DeepSeek 实际调用](real-llm-acceptance.md)。

剩余范围：报告/LaTeX/几何/网格/后处理/求解等其他读取和写入入口，上传的未来预留与元数据，ZIP/备份/导出等长文件峰值；锁内 I/O、历史清理、全局并发和操作系统限制继续归入 RB-14 至 RB-17。RB-12 尚未整项完成，主线仍 33/53、剩 20 项；资源阶段 11/17、剩 6 块。
