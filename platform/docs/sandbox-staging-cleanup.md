# 旧沙箱原始下载暂存清理

后续增量：准备清单和标记的已知部分写入已支持恢复，9 个实际退出位置及 SQLite/PostgreSQL 两进程重复取消验证通过；详见[准备中断与并发取消](sandbox-staging-restart.md)。下文首批证据与当时边界保留。

2026-11-07。已收尾的 S3 沙箱可显式清理原始下载暂存，清理中断后可查询并重试。此功能保留恢复快照、原 ext4 镜像与基线清单，不发布或修改远端项目文件。

## 产品流程与约束

恢复窗口完成“结束旧会话记录”后显示“清理旧会话暂存”。用户确认后发送 `POST /api/v1/terminal/sessions/{sid}/staging-cleanup`，请求包含收尾所保留的 `recovery_id` 和 `confirm:true`；`GET` 同路径只查询。调用者必须仍有原会话和算例权限，收尾组的所有持久绑定和退出观察必须有效。

清理前实际读取并核对整个保留 ZIP。原下载暂存必须具有严格规范的私有路径，清单来源与原会话一致，所有文件内容与下载基线相同，不含未知文件、额外目录、符号链接、重解析点或硬链接。完整清单、文件/目录身份和原始基线写入节点私有 `.terminal-cleanup`；数据库持久意图绑定其 SHA-256 及收尾/快照身份，先提交意图才允许删除。

重试在算例控制锁下核对剩余全部目录和文件，再逐项删除清单中仍匹配的文件及空目录，不递归删除任意目录。原生进程已由收尾凭证核验退出并禁止旧登记继续执行。清理标记阻止残缺副本被重新同步。后台 I/O 在取消时先排空，完成事件提交前，管理准入继续拒绝；不能仅凭目录不存在判为完成。完成回执持久化后重复确认不再删除，新内容出现在旧目录时拒绝操作并恢复管理阻塞。

界面先保存待确认快照再提交；断网后保持待确认状态，重新打开和轮询只发 GET，必须显式点击才重试。清理完成只表示这份原始暂存被清除，其他活动记录仍可阻止移动等管理操作。

## 实际证据

- [S3/WSL 清理结果](../../tmp/sandbox-recovery-ui-retirement-c1quta7r/staging-cleanup-checks.json)：3 项实际基础设施、4 项协议/故障检查；旧收尾检查重复执行但不计作新增覆盖。测试在第一个实际 unlink 完成后使隔离 API 以 77 退出，重启时确认数据库意图已提交、剩余文件与标记真实存在，继续清理后管理检查通过。
- 同一测试验证错误快照、缺少确认、其他用户、内容变更、未知文件、ZIP 损坏及清理后目录重新出现均不会造成越界删除。原镜像和 ZIP 仍在，远端沙箱产物仍为 404。
- [真实 DeepSeek](../../tmp/sandbox-recovery-ui-retirement-c1quta7r/live-result.json)：清理后从快照确认写回真实 shell 生成的随机内容；模型实际选择 `read_text_file` 再续答，**2 次真实调用，8422 tokens，模拟 0**。实际服务 `api.deepseek.com`，模型 `deepseek-flash`。文件读取和完整随机内容通过；模型仍附带说明文字，严格“仅回复字符串”未通过，不将其算作已修复。
- [浏览器结果](../../tmp/sandbox-recovery-ui-retirement-mosyv3dh/staging-browser-checks.json)：13 项，涵盖真实断网、关闭重开仅查询、显式重试、生产 API 回执、ZIP 下载、远端内容未发布，以及 375/812px 明暗主题。实际 API/WSL/S3，无请求拦截或模型替身。
- 两组隔离环境分别核对 7/15 个进程身份退出；开发数据库和端口 8000 未改动。前端构建通过，变更组件与工具模块定向 lint 通过；现有主包体积警告仍在。

## 尚未完成

这不是所有沙箱资源的自动维护：原镜像、导出发布生成的另一份暂存、失败/未完成恢复副本和长期保留快照仍需各自有证据的清理策略。镜像删除仍需注册的原生执行、卷身份/完整哈希、独占锁、无 loop 挂载及恢复互斥。

本轮测试覆盖删除后的真实 API 退出；准备清单或清理标记写入中途退出、完成提交确认丢失、并发确认、跨 worker/PostgreSQL、权限变动与取消等专属矩阵仍需继续。损坏/不完整的准备文件和标记目前保守拒绝，不自动覆盖；孤立准备元数据维护、长锁期限与大目录有界核验仍待补齐。节点小文件写入使用容量预留，物理文件扫描反映已删除缓存；用户额度/跨节点整套结算尚未验收。

主线维持 33/53 完成，剩余 20；资源维持 11/17 完成，剩余 6 块；295 项全功能最终验收均继续，未因此关闭整项。
