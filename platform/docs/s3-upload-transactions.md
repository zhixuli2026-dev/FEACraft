## 远端状态与完成协议

会话元数据位于 `.vibeflow/uploads/<id>/meta.json`，绑定后端地址、bucket 和算例前缀。每个 offset 对应独立的分块数据和记录，记录包含 offset、大小及 SHA-256。先条件创建并核验分块，再按元数据 ETag 条件推进 offset；没有无条件覆盖分支。

分块写入后、进度更新前进程退出，新 API 仍看到旧 offset。重新发送相同内容会核验并复用该分块；不同内容返回冲突。进度更新成功但响应丢失时，查询返回已推进的 offset，旧 offset 的重复写入被拒绝。会话和进度均来自 S3，不依赖原 API 本地目录。

完成请求按分块链流式组装到临时本地文件，并校验分块摘要、完整长度及可选整文件摘要。再次核对远端元数据和创建上传时的目标版本，再把已校验文件交给 S3 文件日志。临时组装文件是可丢弃缓存，发生错误或取消时也尝试清理；进程直接退出留下的本地缓存由后续保留/扫描任务处理，绝不成为恢复权威。

完成事件沿用本地上传的 SQL 唯一回执，与文件日志证明同时提交。数据库未提交时恢复旧目标；已提交但响应丢失时返回原完成结果。重复完成不会覆盖用户后来编辑的文件，已完成会话也不能继续写块或取消。

## 流式日志和清理

S3 日志的旧内容备份、不可变新内容校验、应用和恢复均使用有界流式读取，单次读取最多 1 MiB。HEAD/GET 版本或长度不匹配会拒绝；GET 期间对象删除或替换映射为冲突。临时文件在条件 PUT 完成后关闭，工作线程结束前仍保留算例 SQL 锁。

上传完成前保存不可变清理清单，SQL 回执保存其路径和摘要。提交后仅按清单核验并条件删除分块与会话元数据。清理中退出可继续；外部改动会保留现场并返回 `cleanup_pending`，不会否认已有完成证明。不可变清理清单保留用于审计，未列入清单的对象不会被盲目删除；统一保留期和配额回收仍待后续完成。

取消先条件写入 cancelled 状态，再按当前 ETag 删除会话分块；取消标记保留，删除中断不会让会话重新变成可写。正式完成操作的取消会等待存储线程结束及临时文件清理，再释放锁；竞争编辑须等待，并在恢复后保持其内容。

## 限制与验收

大小限制为单文件 1 GiB、单块 8 MiB、每会话最多 10,000 块；创建响应包含 max_chunks。现有浏览器每块 4 MiB，在最大文件下无需接近块数限制。日志单个对象最多 1 GiB、前后备份总计最多 2 GiB。只有真正执行条件创建/更新/删除的 S3 后端可创建上传；实测旧 SeaweedFS 3.99 在创建会话之前返回 422，新版 4.52 已通过。
