# LaTeX 结果读取的算例锁与存储预算

`GET /api/v1/cases/{case_id}/latex/results` 在短事务中选定发布，记录算例事件序号、修订、发布摘要和成功作业。随后分块核验归档和当前兼容文件的 SHA-256，在数据库事务之外读取来源及上游状态。归档和来源核验共用现有读取名额与请求期限。返回前复核授权、算例状态、发布选择及依赖查询结果。

独立 API 可以直接从认证 SeaweedFS 核验历史发布。当前发布仍按已有来源规则核对 `caseDict`、受影响的文件和上游发布。S3 检查当前来源时可以使用请求私有的临时视图，完成后清理。

## 实测

- 使用实际 WSL `pdflatex` 构建两页 PDF，归档含 4,945,000 B 的 LaTeX 源文件。旧版公开接口暂停在文件读取后，另一条 SQLite 连接取得写锁失败。新版文件系统和认证 SeaweedFS 均允许同案提交。认证 S3 的独立读取端未生成整套归档缓存。[旧版对照](../../tmp/N4-05-latex-result-20261122/baseline.json) · [文件系统回执](../../tmp/N4-05-latex-result-20261122/fs.json) · [认证 S3 回执](../../tmp/N4-05-latex-result-20261122/s3.json)
- 同案改源期间的读取返回 `409 input_stale`。旧版清单及工具链在重读后保持一致，来源标记为过期。停顿超过请求期限返回 504，解除停顿后可重试。[阶段回执](../../tmp/N4-05-latex-result-20261122/validation.json)
- 两种存储均拒绝不匹配的主文件、跨账号读取，以及长度相同但内容被改写的归档源文件。恢复原字节后历史结果可正常读取。测试使用隔离存储，模型调用 0。[复验脚本](../../tmp/N4-05-latex-result-20261122/check.py)
- SyncTeX 复用同一套兼容文件摘要校验。文件系统复验通过真实原生定位、同案保存、历史第 7 行回读和超时后重试。[SyncTeX 兼容回执](../../tmp/N4-05-latex-result-20261122/synctex-compat.json)
