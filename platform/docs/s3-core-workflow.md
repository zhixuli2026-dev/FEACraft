# S3 正式工程流程

本批为 `geometry.preview/export → mesh.generate → solve.openfoam → postprocess.run → report.build` 接通远端输入读取，沿用独立执行目录、不可变结果包、条件兼容文件和数据库发布版本。验收已完成，规范记录在 `tmp/mainline-N2-s3-core-workflow-evidence/`；S3工程8项、Markdown3项、读取视图6项、存储清单4项、本地工程8项、普通文档23项及准入16项通过。

## 实现边界

`case_read_view.py` 为需要文件路径的既有解析器提供短期目录：按远端对象 ETag 条件读取，读取前后核对对象集合，排除执行元数据，结束或取消后删除自己创建的临时目录。本地文件存储继续使用原目录，不复制或删除用户目录。后台下载收到取消时先排空，再清理已进入的上下文。

几何、网格、求解、后处理的输入摘要与准备阶段均通过上述读取视图；求解确认与后处理确认也核对远端实际场文件。报告生成和独立重编译显式读取所属输入目录中的 caseDict、质量报告、后处理证据和图片。业务门禁仍检查原算例前缀，避免把临时目录误当成远端算例路径。Markdown 原生准备与文档提交保护中的 caseDict 哈希同样支持远端读取。

另外修复统一存储接口的路径差异：S3 列举子目录原先返回相对子目录的路径，文件后端返回相对算例的路径，导致报告门禁误判目录变化。两后端现在都返回算例相对路径；子目录只限制筛选范围，目录标记不作为文件，分页结果保持排序。返回路径可以直接交给 `get_bytes`。

正式处理器在绑定时验证后端条件写入、条件删除能力；当前仅允许这六个正式处理器及已有五种通用命令的 S3 发布。其他十四个正式处理器继续实施，不宣称所有专业工具已支持 S3。默认文件存储和 `allow_partial_s3` 限制保留。

## 验收方式

- `s3_core_workflow_smoke.py`：隔离 SQLite API、SeaweedFS 4.52，实际 CadQuery、OpenFOAM、后处理与 Pandoc；B/C/D/E 确认、解析解均温 350 K、HTML/DOCX、另一个空缓存 API 的递归读取和引用、修改几何后的下游过期及历史引用。
- 同一脚本 `--fs`：在隔离本地文件存储运行相同工程流程，两 API 共享该隔离文件存储。
- `s3_markdown_report_smoke.py`：远端 Markdown、相对路径 SVG、公式、HTML/DOCX、空缓存读取、图片变更导致当前版本过期及历史保留。
- `case_read_view_smoke.py`：真实对象读取、空文件、元数据排除、对象集合变更、条件下载失败及两种取消路径的清理、本地目录保留。
- `s3_listing_smoke.py`：真实 S3 分页与文件后端清单等价、返回路径可直接读取、子目录及算例边界、目录标记排除与路径越界拒绝。
- `ordinary_document_smoke.py` 与 `document_admission_smoke.py`：本地普通文档、来源冻结、原生准备和取消兼容。

失败记录保留：首轮网格夹具分辨率未达到既有质量阈值，改用已有正式报告测试的 20×4×4 网格，未降低门禁；第二轮发现求解确认误读本地缓存；第三轮在报告准备遇到文档准入仍读本地 caseDict。独立 Markdown 测试也复现了最后一项的 HTTP 500。本地工程报告检查最初错误要求输出包含字面量 `350`，实际数值为 `349.99999994412065`，已改为先按 1e-6 容差验证解析值，再核对报告包含实际计算结果。

第四轮通过四次确认但报告未启动，显式调度诊断返回 HTTP 400，定位到上述 S3 子目录路径差异。确认接口会保存已成功的确认，并在后续调度失败时返回 `workflow_dispatch.status=pending`；新测试保存并检查每次确认的调度结果，避免只凭 HTTP 200 等待到超时。

第五轮立即暴露首次路径修复改变了内部 `_s3_list` 语义，封存清单因此拒绝匹配。最终将算例相对路径转换限制在公共 `list_tree`，内部尝试/发布清单继续使用前缀相对路径，并增加私有清单兼容断言。目录标记排除、目录末尾斜杠规范化和分页排序保留。

第六轮在 E 确认后的报告准备超过夹具的 30 秒 HTTP 等待；后续夹具将该完整链路的请求等待限定为 120 秒，逐请求记录耗时，不自动重试写入。最终耗时记录保存在规范证据的 `http-timing-summary.json`，属于单次正确性验收的观察，不能替代响应性能验收。未改变产品的求解/原生任务期限。
