# 手动压缩与摘要交接

FF-F37A 的压缩入口会保留指定数量的最近消息。重复压缩复用上一份摘要，只将新纳入压缩范围的历史发给模型。压缩输入最多 12,000 字符，并把历史标为引用资料。摘要作为新的系统事件追加，原消息和既有摘要可继续从历史读取。相同范围再次压缩时返回无需压缩。

模型调用期间释放数据库事务。摘要返回后，接口再复核用户授权、会话归属、执行状态和事件头。压缩期间新增消息时返回 `409 history_changed`，用户可以按最新历史重试。浏览器将压缩进度与聊天输出分开管理。切换会话时，压缩结果从发起会话的服务端历史恢复。

FF-F37B 的交接在同一算例下新建会话，保留原会话的模型、provider 配置与权限模式。新会话从最新摘要开始。源会话还没有摘要时，使用调用方指定长度内的最近文字。两条路径都只创建一条交接历史事件。
