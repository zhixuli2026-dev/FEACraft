# SU2 独立运行与结果发布

本次将本地文件存储的 `/su2:solve` 接入 `su2.solve@1` 处理器：配置、网格、重启输入及子区域配置封存在作业自己的目录，真实 SU2 子进程受持久化监督；成功结果形成不可变版本，再更新原下载路径。发布描述为 `su2.v1`，不同主配置文件使用不同发布通道。

## 行为与实现边界

- 按 SU2 配置语法读取选项、注释和续行；递归收集 CONFIG_LIST，遵循进程工作目录解析相对路径。缺失必需文件、越界路径和配置循环在创建作业前报错。多区域共用网格和各区域配置均受输入校验保护。
- SOLUTION_FILENAME 支持原生区域、实例、时间序号后缀；实际重启文件进入封存。已存在的普通输出不会被复制进新求解目录。重启输入同时作为输出时，允许本次真实求解更新它；后续“当前结果”校验用已发布摘要辨认这次更新，保留原始输入和不可变历史。
- 原生执行的可执行文件摘要、worker 摘要、输入清单、执行标识、输出清单、日志及返回码组成收据。发布要求真实进程停止证据、原生成功退出日志和本次新产生的非空结果；只有成功文字的空操作无法发布旧成果。
- 输入变化、原来缺失的辅助输入出现、输出被用户编辑、取消、私有配置或收据损坏，均不能覆盖已有结果。复制阶段 API 退出后，可从已验证的发布意图补交原作业，不重复启动求解。
- 单区域历史文件使用 CONV_FILENAME；多区域总体历史文件按原生 CMultizoneOutput 使用主配置路径的第一个点之前部分加表格扩展名。首次多区域验收发现此文件遗漏，已补入结果清单；失败记录保留。
- `runtime.dat` 和 `runtime.cfg` 若存在也封存，并监测从缺失到出现的变化。这是保守的输入一致性保护，不代表 SU2 8.5 启用在线修改配置或运行中热更新。

## 验收

`server/su2_publication_smoke.py --postgres` 使用真实 SU2 8.5.0 OpenMP。验证 NACA0012 的 5,233 个节点、10,216 个单元及密度、压力、温度、马赫数的有限性与物理范围；该短迭代样例不用于宣称气动力收敛精度。覆盖二进制和 ASCII 重启续算、两个独立区域、空白配置路径、幂等、当前/历史引用、输入及目标冲突、空操作、配置/收据破坏、取消和 API 退出后的发布恢复。

`professional_stop_smoke.py` 在真实 SU2 已产生迭代历史后执行取消、超时、API 退出，检查实际求解进程全部退出、无关进程仍存活、中断输出没有写回算例。检查位置随迁移改为私有目录与持久化子执行身份，原有停止断言保留。

`professional_launch_smoke.py` 保留 CalculiX、SU2 的普通及含空白、百分号、与号文件名求解兼容检查。开发数据库和端口 8000 不参与测试。

最终双库各17场景通过，真实中断3项与原启动兼容4项通过。规范证据：`tmp/mainline-N2-su2-publication-evidence/evidence-origin.json`。
