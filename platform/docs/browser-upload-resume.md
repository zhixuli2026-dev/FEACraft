# 浏览器上传恢复与验收

当前版本在首次创建前将浏览器生成的上传标识持久化，并通过 `Idempotency-Key` 发送到服务端。创建响应丢失后，刷新会按当前账户、算例和标识查询同一会话；续传读取服务端确认的偏移。创建尚未抵达时，用户也可以取消这个标识。旧版本已保存服务端上传 ID 的记录可继续使用；旧版缺少服务端 ID 的记录需要用户先结束本机记录，再在“上传恢复”中核对原会话。

## 2026-11-05 版本的行为与验收

2026-11-05：FF-H17 的页面重载续传已接通。主线仍为 23 完成、11 进行中、19 待开始，剩余 30 项。这里关闭的是 N2-06/FF-H17 的浏览器恢复子项，不是这两个完整大项；295 项原始功能要求不删减。

大于 16 MiB、最多 1 GiB 的文件在上传前按 4 MiB 分块校验内容。浏览器 IndexedDB 只存当前账户/算例的目标版本、上传 ID、进度和分块 SHA-256，不存文件字节或认证信息。刷新后重新选择原文件，再校验所有内容；改名但内容一致可以继续，同名同大小而内容不同会拒绝。每次实际上传前再次核对该分块。校验读取每次最多 4 MiB；该分块摘要不是服务端整文件 SHA-256，不会冒充整文件摘要发送。

服务端 offset 是恢复依据。刷新或切换算例保留进度，用户可暂停，明确取消才删除已知会话。最后一个分块已到达时，刷新后无需重新选择文件就可完成提交。完成请求的响应丢失后，读取 SQL 完成回执即可确认结果，不再发布文件，不会覆盖后来的编辑；取消请求遇到已经提交的上传也显示实际完成结果。

本机记录损坏时，只能由用户明确清除损坏记录，不根据不可信 ID 删除服务端数据。存储不可用时，大文件在发起创建请求前停止；普通小文件上传仍可使用。记录按账户和算例分隔，IndexedDB 事务阻止旧窗口覆盖新上传、复活已取消记录，或让同一准备意图绑定两个不同服务端会话。服务器仍负责权限、offset 连续性、目标版本和完成一致性。

创建会话响应丢失时，尚未传输分块，只能恢复本机准备意图并重试创建；原未知 ID 的空会话可能残留。本批没有增加创建请求幂等键，也没有自动寻找或清除这种会话。浏览器存储被清除、更换浏览器/设备时，不承诺找回本机恢复记录。恢复后的文件传输仍需用户操作。
