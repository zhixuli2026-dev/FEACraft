# 普通报告结果读取的算例锁与存储预算

`GET /api/v1/cases/{case_id}/report/results` 在短事务中选定发布，记录修订、算例事件序号、发布状态和成功作业。随后在事务外分块核验归档，并检查当前来源及上游依赖。归档和来源核验共用现有读取名额与请求期限。返回前再次检查授权、发布选择及依赖。普通报告保留 `manifest`、`toolchain` 和 `publication` 响应字段。

独立 API 可直接从认证 SeaweedFS 读取并校验归档成员。测试中读取端未生成整套发布缓存。当前来源核验可使用请求私有的临时视图，完成后清理。

## 实测

- 通过公开构建接口运行实际 Pandoc，生成 4,922,161 B 的 HTML 和 3,700,191 B 的 DOCX。旧接口暂停在归档成员读取后，独立 SQLite 连接无法取得写锁。修复后，文件系统和认证 SeaweedFS 均允许同算例保存。[旧版对照](../../tmp/N4-05-report-result-20261122/baseline.json) · [文件系统回执](../../tmp/N4-05-report-result-20261122/fs.json) · [认证 S3 回执](../../tmp/N4-05-report-result-20261122/s3.json)
- 并发修改源文件时，进行中的读取返回 `409 input_stale`。指定原发布重读时，清单、工具链与原值一致，来源标记为过期。读取暂停超过期限返回 `504 report_result_timeout`，解除暂停后可重试。[阶段回执](../../tmp/N4-05-report-result-20261122/validation.json)
- 两种存储均通过跨账号 404 和同长度归档损坏的 `409 evidence_invalid`。恢复 DOCX 原字节后可以重新读取历史结果。验收使用隔离账号和存储，模型调用 0。[验收脚本](../../tmp/N4-05-report-result-20261122/check.py)
- LaTeX 共用结果读取流程。在本机文件系统使用实际 WSL `pdflatex`，复验 4,945,000 B 源文件、同案保存、并发失效、历史结果、期限后重试及归档完整性。[LaTeX 复验](../../tmp/N4-05-report-result-20261122/latex-compat.json)
