# 封存输入与沙箱作业的权限传递

2026-11-16，接续文件编辑权限延续。主线 48/53、剩 5 项；资源 11/17、剩 6 块；295 项完整交付范围保持。

## 实现

封存输入从已有目录树描述中选取本次输入的目录和摘要匹配文件，将精简后的描述作为 `.vibeflow/tree-state.json` 内部文件一起封存。它与其他输入一样进入数据库清单、文件摘要校验、复制、S3 条件读取和存储峰值估算；仍受原输入总量及数量限制，不创建脱离清单的旁路文件。

重试直接使用原封存副本及其描述，不重新读取当前项目权限。S3 初始准备同时核对权限描述，重建选中范围内的空目录；使用已有 `Cache.directories` 登记目录后再创建，保证原缓存清理能够识别。S3 本地输入缓存丢失时，已有冷恢复会连同描述一起重新获取。

已有沙箱启动器在真正的 Linux 执行副本中应用该描述。成果校验仍先验证完整封存清单，然后只将工程输入交给原 handler；权限描述属于运行内部文件，不能因此改变 handler 的工程输入契约。
